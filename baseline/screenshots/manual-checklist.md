# 수동 확인 체크리스트 (자동화 스크린샷/녹화로 못 담은 것)

Playwright(`baseline/scripts/capture.js`)로 대부분의 화면·상태·인터랙션을 자동 캡처했다.
아래는 마우스 hover 등 스크립트로 재현하는 의미가 적어 수동 확인용으로 남기는 항목이다.

- [ ] 달력 태그(메모/가계부) 마우스 오버 시 나타나는 툴팁(`MemoTooltip`/`AccountBookTooltip`) 실제 표시 위치·타이밍
- [ ] 비밀번호 표시/숨기기 아이콘(👁) 클릭 시 인풋 타입 전환 애니메이션
- [ ] 드래그 앤 드롭(`@dnd-kit`)으로 가계부 카테고리 순서 변경 시 동작 (accountbook/category 페이지)
- [ ] Daum 우편번호 검색 팝업(회원정보 수정 화면의 "우편번호 찾기") — 외부 팝업창이라 자동화 스크립트에서 제외

## 참고: 자동 캡처에서 의도적으로 생략/대체한 것

- 게시판 글쓰기(자유게시판)는 폼 화면만 캡처하고 실제 등록(제출)은 하지 않음 — 라이브 공개 게시판에
  테스트 게시물이 남는 것을 피하기 위함.
- 회원정보 수정(`/user/accountbook/... ProfileEdit`)의 "회원정보수정"/"탈퇴하기" 버튼은 클릭하지 않음 —
  테스트 계정의 비밀번호 변경/탈퇴가 실제로 발생하면 이후 측정이 막히므로 화면만 캡처.
